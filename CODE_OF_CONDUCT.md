# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, critique ideas rather than people, and
make room for newcomers. Harassment of any kind is not tolerated.

That applies everywhere the project lives: issues, pull requests,
discussions, and anywhere you represent it.

## Reporting

To report behaviour that breaks this code, contact the maintainer privately
through the email address on their [GitHub profile](https://github.com/bizpers11991-code),
or, if none is listed, through a
[private security advisory](https://github.com/bizpers11991-code/phonehome/security/advisories/new)
marked "Code of conduct" (it is private to the maintainers). Reports are kept
confidential. Enforcement follows the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
